Идея такая: раньше мы отправляли в Ozon товары агрегированно (например, `quantity=3` одним элементом). Теперь мы формируем payload **разбивая всё по 1 единице** — в `products` отправляем список из элементов вида:

- причём если в заказе `quantity=2` по одному SKU — будет **2 элемента** с `quantity: 1`
- если несколько строк `order_items` (несколько позиций) — будет по одному элементу на каждую единицу каждой строки
