1. Общая идея проекта

Нужно разработать Python-проект stigma_fbs, который будет работать с маркетплейсами Ozon и Wildberries и в дальнейшем использоваться для обработки FBS-заказов.

На первом этапе реализуется только Ozon.

Первая версия проекта должна:

подключаться к API Ozon,
получать FBS-заказы,
сохранять/обрабатывать их внутри проекта,
выводить их на веб-странице,
показывать заказы по разным статусам,
быть развернутой на сервере в папке /srv/stigma_fbs.

Сейчас задача — не автоматизация сборки, не печать этикеток и не смена статусов, а именно получение и удобный просмотр FBS-заказов Ozon через веб-интерфейс.
