1. Общая идея проекта

Нужно разработать Python-проект stigma_fbs, который будет работать с маркетплейсами Ozon и Wildberries и в дальнейшем использоваться для обработки FBS-заказов.

На первом этапе реализуется только Ozon.

Первая версия проекта должна:

подключаться к API Ozon,
получать FBS-заказы,
сохранять/обрабатывать их внутри проекта,
выводить их на веб-странице,
показывать заказы по разным статусам,
быть развернутой на сервере в папке /srv/stigma_fbs.

Сейчас задача — не автоматизация сборки, не печать этикеток и не смена статусов, а именно получение и удобный просмотр FBS-заказов Ozon через веб-интерфейс.

- показывать заказы в браузере (таблица + фильтры + сводка по статусам);

Кратко по фактам из ваших данных и API Ozon.

### Что уже есть в самом заказе (строка товара в `posting`)
В `products[]` из `/v3/posting/fbs/list` у вас по сути: **SKU, `offer_id`, название, количество, цена, валюта**, флаги вроде маркировки/IMEI. **Штрихкода в этой строке нет**, цвета там тоже нет.

### Что можно дотянуть отдельными методами (как мы уже делаем с фото)

1. **Баркод — да, можно.**  
   В **`/v3/product/info/list`** у товара есть массив **`barcodes`** (у вас, например, `['2046566363973']`).  
   Плюс в **`/v4/product/info/attributes`** в ответе есть поле **`barcode`** (одна строка).

2. **Цвет — да, но не отдельным полем «color» в одном месте.**  
   Он лежит в **`/v4/product/info/attributes`** в массиве **`attributes`**: это пары **`id` + `values[].value`**.  
   Для вашего примера цвет приходит как атрибут с **`id: 10096`** и значением **`черный`**.  
   Важно: **номер атрибута может отличаться по категории/типу товара** (`type_id` / `description_category_id`), поэтому надёжнее либо завести маппинг «цвет» под ваши типы, либо один раз выгрузить справочник атрибутов категории и искать нужный.

3. **Что ещё реально тянуть с товара (из того же `/v4/product/info/attributes`):**  
   габариты (**высота/ширина/глубина**, единицы), **вес**, **размер** (у вас видны отдельные атрибуты вроде XXL), пол, состав ткани, сезон, тип роста/объёмы и т.д. — всё, что вы завели в карточке в Ozon.

4. **Из `/v3/product/info/list` дополнительно:**  
   **остатки**, **цены** (min/old/price), **комиссии**, **индексы цен**, **видимость**, **архив** и т.п. — для FBS-отгрузки часто избыточно, но технически доступно.

Итого: **баркод — без проблем, тем же батчем по SKU, что и картинки.** **Цвет — через `/v4/product/info/attributes`**, с аккуратностью к `id` атрибута по категории. Если скажешь «давай в таблицу», могу добавить колонки **Баркод** и **Цвет** и догружать их при синхронизации.
